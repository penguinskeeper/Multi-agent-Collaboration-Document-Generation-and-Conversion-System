# 截图素材

README 顶部的演示图放在这里。一个多智能体项目，**界面比文字有说服力**——尤其是右侧那条
实时进度时间线，光看文字描述很难传达。

## 当前已有

| 文件名 | 尺寸 | 内容 | 用在哪 |
|---|---|---|---|
| `demo-chat.png` | 1920×940 | 一次真实任务完成的效果：左栏返回 Markdown 表格结果，右栏时间线连续列出 `execute_sql_query` 工具调用，右上角状态灯为绿色"实时通道已连接" | README 顶部主图 |
| `demo-home.png` | 1920×940 | 服务启动后、尚未发任务时的初始界面：三栏布局全貌（对话 / 执行进度 / 生成的文件），状态灯为"未连接" | 备用（界面总览） |

> `demo-home.png` 目前未用于 README。它的价值在于布局更干净（无内容遮挡），
> 适合作为"界面总览"图；若要启用，注意它右上角是**未连接**状态，
> 需在配文里说明"WebSocket 建立后转为绿色"，否则容易被误读为启动失败。

## 截图注意

- 窗口宽度建议 ≥ 1280px，浏览器缩放 100%，正文才清晰（现有两张均为 1920px 宽）；
- 用 PNG，单张控制在 500KB 以内（现有两张为 144KB / 56KB，达标）；
- **别把 API Key 截进去**——弹窗输入密钥那一幕不要截，或先打码；
- 本机是 100% 缩放的 1920 宽屏，直接 `Win + Shift + S` 框选浏览器窗口即可。

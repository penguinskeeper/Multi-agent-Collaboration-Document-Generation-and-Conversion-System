# 儿童与老年人用药安全指引

## 一、儿童用药核心原则

1. **优先选择儿童专用剂型**（混悬液、颗粒剂、滴剂），按体重或年龄精确计算剂量，不可简单把成人药减半使用。
2. 家长应使用药品自带的量杯、滴管、量勺量取，**家用汤勺误差可达 50% 以上**。
3. 禁用/慎用清单：
   - 18 岁以下禁用喹诺酮类（左氧氟沙星等，影响软骨发育）
   - 12 岁以下不建议服用成人复方感冒药
   - 2 岁以下不建议自行使用镇咳药（抑制咳嗽反射有痰堵风险）
   - 儿童退热首选对乙酰氨基酚（≥2-3 月龄）或布洛芬（≥6 月龄），**阿司匹林禁用于儿童退热**（瑞氏综合征风险）
4. 药品要放在儿童看不见、够不到的地方；喂药时不要骗孩子说"是糖果"，避免误食。

## 二、儿童发热处理流程（家庭版）

1. 体温＜38.5℃且精神状态好：物理降温（温水擦拭、减少衣物）、多喂水，观察。
2. 体温≥38.5℃或明显不适：按体重给对乙酰氨基酚或布洛芬，记录用药时间与剂量。
3. 以下情况立即就医：3 个月以下婴儿发热；热性惊厥；发热伴皮疹、呕吐脱水、精神萎靡；发热超过 72 小时。

## 三、老年人用药核心原则

1. **起步剂量减半、缓慢加量**：老年人肝肾功能下降，药物代谢慢，"低起点、慢滴定"。
2. 定期"洗方"：每 3-6 个月带全部在用药品（含保健品）让医师或药师审一遍，停用无明确指征的药物，减少多重用药相互作用。
3. 常见高风险药物提示：
   - 苯二氮卓类安眠药（地西泮等）：跌倒骨折、认知损害风险，尽量短用
   - 非甾体抗炎药（布洛芬等长期用）：胃肠出血、肾损伤风险
   - 糖尿病患者使用降糖药注意低血糖识别（老人低血糖症状常不典型）
4. 建立用药清单并随身携带：药名、剂量、频次、开方医生，就医时出示。

## 四、家庭药箱管理建议

1. 每季度检查一次有效期，过期药不服用，投放到药店或社区的过期药品回收点，不要随意丢弃或冲入下水道。
2. 内服药与外用药分开存放，原包装保存（保留说明书与批号）。
3. 需要冷藏的药品（如胰岛素、部分生物制剂）放冰箱 2-8℃ 冷藏层，不可冷冻（另有说明除外）。
4. 药箱避免放在厨房、卫生间等高温高湿环境。

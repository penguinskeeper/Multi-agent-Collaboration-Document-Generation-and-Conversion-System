# 慢性病用药管理知识（高血压、糖尿病）

## 一、高血压用药

### 常用降压药五大类

1. 钙通道阻滞剂（CCB）：氨氯地平、硝苯地平缓释片。常见副作用：踝部水肿、面部潮红、牙龈增生。
2. 血管紧张素转换酶抑制剂（ACEI）：依那普利、培哚普利。干咳为典型副作用；双侧肾动脉狭窄、高钾血症、孕妇禁用。
3. 血管紧张素Ⅱ受体拮抗剂（ARB）：缬沙坦、氯沙坦。干咳少，ACEI 不耐受者的替代选择；孕妇禁用。
4. 噻嗪类利尿剂：氢氯噻嗪、吲达帕胺。注意低钾血症、尿酸升高（痛风者慎用）。
5. β受体阻滞剂：美托洛尔。心动过缓、哮喘患者慎用；不可骤停（反跳）。

### 用药管理要点

1. 降压治疗强调**长期平稳达标**（一般目标＜140/90mmHg），不可凭感觉停药、换药。
2. 长效制剂建议晨起一次服用；夜间高血压者遵医嘱调整服药时间。
3. 家庭自测血压：早晚各测一次（服药前），坐位休息 5 分钟后测，连续 7 天取规律值供医生调药参考。
4. 单药效果不佳时医生常联合用药（如 ARB+CCB），患者不应自行叠加同类药物。

## 二、糖尿病用药

### 常用降糖药要点

1. 二甲双胍：2 型糖尿病一线用药。常见胃肠反应，随餐或餐后服用可减轻；肾功能不全（eGFR<30）禁用；做增强 CT 前后 48 小时停用。
2. 磺脲类（格列美脲等）：促胰岛素分泌，低血糖风险较高，老年患者尤其警惕。
3. α-糖苷酶抑制剂（阿卡波糖）：随第一口饭嚼服，针对餐后血糖；低血糖时必须口服葡萄糖（蔗糖分解受抑制）。
4. DPP-4 抑制剂（西格列汀等）：低血糖风险低，肾功能不全者按说明调量。
5. SGLT-2 抑制剂（达格列净等）：注意泌尿生殖感染风险、多饮水；脱水状态暂停用。
6. 胰岛素：类型（超短效/短效/中效/预混）与注射时间严格对应，注射部位轮换，避免同一部位反复注射致脂肪增生影响吸收。

### 用药管理要点

1. 监测方案：口服药者每周至少 2-4 次指尖血糖（空腹+餐后 2 小时轮换）；胰岛素治疗者监测更频。
2. 低血糖识别与处理：心慌、出汗、手抖、饥饿感→立即进食 15g 速效糖（葡萄糖片/含糖饮料），15 分钟复测，未缓解重复（15-15 原则）。
3. 携带"糖尿病卡片"注明用药情况，便于突发低血糖时施救。
4. 血糖控制目标因人而异（年轻无并发症者较严，老年体弱者放宽防低血糖），以主治医生个体化目标为准。

## 三、慢病随访提示

1. 高血压、糖尿病患者建议每 3 个月复查血压/血糖控制情况，每年评估肝肾功能、血脂、眼底、尿微量白蛋白。
2. 任何"根治高血压/糖尿病"的宣传均属虚假，规范用药+生活方式管理才是正道。

## 怎么用

1. 在 RAGFlow 中新建知识库，把本目录的 9 个文件上传并完成解析（chunk）；
2. 拿到知识库对应的助手 ID，填进 `.env`：

   ```env
   RAGFLOW_API_URL=<你的 RAGFlow 地址>
   RAGFLOW_API_KEY=<你的 API Key>
   ```

3. 重启服务。知识库子智能体会在这时被启用——在此之前它会按设计被跳过（优雅降级）。

> RAGFlow 无论是云端付费还是本地自建（建议 16GB 内存以上）都有一定门槛，
> 所以未配置时知识库子智能体自动降级是**预期行为**，不是 bug。主链路
> （搜索 → 汇总 → 报告）不受影响。

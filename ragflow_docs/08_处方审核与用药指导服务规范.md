# 处方审核与用药指导服务规范

## 一、处方审核要点（药师审方"四查十对"）

1. 查处方，对科别、姓名、年龄；
2. 查药品，对药名、剂型、规格、数量；
3. 查配伍禁忌，对药品性状、用法用量；
4. 查用药合理性，对临床诊断。

### 常见不合理处方类型

1. 重复用药：如同时对乙酰氨基酚含量相同的两种复方感冒药。
2. 超说明书剂量：如对乙酰氨基酚一日超过 2g（保守安全线）。
3. 配伍禁忌：如氯吡格雷与奥美拉唑联用、单胺氧化酶抑制剂与右美沙芬联用（5-羟色胺综合征风险）。
4. 特殊人群禁忌：孕妇用孕晚期禁用 NSAID；儿童用喹诺酮类；青霉素过敏史者开青霉素类。

## 二、用药指导（发药交待）标准话术框架

1. **怎么用**：明确给药途径、时间点（餐前/餐中/餐后/睡前）、疗程。
   - 肠溶/缓释制剂：整片吞服，不可掰开嚼碎。
   - 眼药水：开封后 4 周内用完（无防腐剂型 1 周内）。
2. **注意事项**：忌酒清单（头孢类+酒=双硫仑样反应，服药前后 7 天禁酒）；嗜睡副作用者避免驾驶。
3. **漏服怎么办**：想起时立即补服；若接近下一次服药时间则跳过，绝不加倍。
4. **何时复诊**：症状未缓解或加重的时限（退热药 3 天、抗生素足疗程后评估）。
5. **储存要求**：按说明书温度、避光要求，儿童不可触及处。

## 三、双硫仑样反应（高频咨询）

1. 定义：使用某些药物后饮酒，乙醛蓄积引起面部潮红、心悸、呼吸困难、血压下降，严重可休克。
2. 高风险药物：头孢菌素类（头孢哌酮、头孢曲松等）、甲硝唑、替硝唑、呋喃唑酮。
3. 时间窗：**用药期间及停药后 7 天内均应禁酒**，包括白酒、啤酒、红酒、含酒精食物（酒心巧克力、醉虾）及藿香正气水（含乙醇剂型）。
4. 处置：出现症状立即停药，轻者卧床补水观察，重者拨打急救电话。

## 四、特殊剂型用药指导速查

1. 吸入剂（布地奈德福莫特罗等）：先呼气→含住吸嘴深吸气同时按压→屏气 5-10 秒→漱口（防口腔念珠菌感染）。
2. 硝酸甘油片：心绞痛发作时舌下含服，坐位（防体位性低血压），5 分钟不缓解可再含 1 片，最多 3 片仍不缓解立即拨打急救电话。
3. 胰岛素注射：注射部位轮换（腹部、大腿、上臂），预混胰岛素注射前充分混匀，未开封 2-8℃ 冷藏、开封后 25℃ 内 4 周用完。
4. 透皮贴剂：贴于清洁干燥无破损皮肤，部位轮换，洗澡前检查边缘是否翘起。

## 五、不良反应上报

1. 用药后出现说明书未记载或较严重的不适，建议患者停药并就医。
2. 药店按国家药品不良反应监测制度上报可疑即报原则，严重的 15 日内上报，死亡病例立即上报。

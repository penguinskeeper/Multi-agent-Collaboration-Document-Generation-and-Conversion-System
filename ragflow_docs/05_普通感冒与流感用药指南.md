# 普通感冒与流行性感冒用药指南

## 一、普通感冒

### 病因与特点

普通感冒多由鼻病毒、冠状病毒等病毒引起，属自限性疾病，通常 5-7 天自愈。主要症状：鼻塞、流涕、打喷嚏、咽痛、低热、咳嗽。

### 用药原则

1. **抗病毒药物对普通感冒无效，抗生素更无效**——治疗以对症缓解为主。
2. 单一症状优先选单一成分药物：
   - 发热头痛：对乙酰氨基酚或布洛芬
   - 鼻塞流涕：伪麻黄碱（收缩血管）或氯苯那敏（抗组胺，有嗜睡副作用）
   - 干咳：右美沙芬；有痰咳嗽：氨溴索、乙酰半胱氨酸等祛痰药
3. 复方感冒药（如含伪麻黄碱+右美沙芬+对乙酰氨基酚的复方制剂）一次只选一种，**严禁与单一成分退烧药叠加服用**，否则有对乙酰氨基酚过量致肝损伤风险。
4. 多休息、多饮水，保持室内通风。

## 二、流行性感冒

### 病因与特点

由甲型/乙型流感病毒引起，起病急、高热（39-40℃）、全身酸痛乏力明显，传染性强，冬春季高发。

### 用药原则

1. **发病 48 小时内**使用抗流感病毒药物（如奥司他韦，处方药）效果最佳，可缩短病程、降低重症率。
2. 奥司他韦：成人一次 75mg、一日 2 次、连服 5 天；儿童按体重给药，1 岁以上可用，需遵医嘱。
3. 高热者对症退热（对乙酰氨基酚/布洛芬）；密切观察有无持续高热、呼吸困难、意识改变等重症信号，出现即就医。
4. 老人、孕妇、慢性病患者、儿童属重症高危人群，建议尽早就医评估抗病毒治疗。

## 三、就医警示信号

出现以下情况应及时就医，不要自行用药拖延：

1. 发热超过 3 天不退，或体温持续 39℃以上。
2. 呼吸急促、胸闷胸痛、口唇发绀。
3. 剧烈头痛、颈部僵硬、意识模糊。
4. 咳脓痰、痰中带血。
5. 婴幼儿拒奶、精神萎靡、高热惊厥。

## 四、常见误区提示

1. "输液好得快"——普通感冒输液无益，徒增风险。
2. "感冒了吃抗生素消炎"——抗生素对病毒无效，滥用导致耐药。
3. "多种感冒药一起吃效果更好"——成分重复叠加，药物过量中毒风险高。
4. "板蓝根预防流感"——缺乏可靠证据，不能替代疫苗接种。
